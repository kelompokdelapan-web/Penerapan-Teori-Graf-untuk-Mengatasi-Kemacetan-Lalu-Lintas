# Discrete Journal — Website Artikel

Website statis responsif untuk publikasi artikel:
"Penerapan Teori Graf untuk Mengatasi Kemacetan Lalu Lintas".

## Isi paket
- `index.html` — halaman website utama.
- `README.md` — petunjuk penggunaan dan publikasi.

## Menjalankan secara lokal
1. Ekstrak ZIP.
2. Buka folder `discrete-journal-website`.
3. Klik dua kali `index.html` untuk membukanya di browser.

Tidak memerlukan instalasi, database, atau server khusus.

## Publikasi online
Website ini berupa situs statis. Untuk mempublikasikannya, unggah isi folder ini ke layanan hosting statis seperti GitHub Pages, Netlify, atau layanan hosting web yang mendukung HTML statis.

## Catatan editorial
Konten artikel diambil dari dokumen artikel pertama yang diberikan. Data jaringan jalan bersifat ilustratif. Nilai ruas D–E menggunakan 4 menit sesuai perhitungan pada dokumen artikel sumber.
